# Audio Player 🎵

נגן מוזיקה פשוט ויפה לאנדרואיד — מוצא לבד את כל השירים בטלפון, עם פלייליסטים, מיון, שיתוף ומסך נעילה. בלי חשבון ובלי פרסומות.

## ⬇️ הורדה

**[להורדת הגרסה האחרונה](https://github.com/MICHAEL4830/audio-player-download/releases/latest)** — בדף שנפתח, לחץ על הקובץ שמסתיים ב-`.apk`.

## איך מתקינים

1. מורידים את קובץ ה-APK מהקישור למעלה, בטלפון.
2. פותחים את הקובץ (מההתראה או מתיקיית ההורדות).
3. אם הטלפון שואל, מאשרים "התקנה ממקור לא ידוע" לדפדפן, וחוזרים להתקנה.
4. פותחים את Audio Player ומאשרים גישה למוזיקה.

כדי לעדכן — מתקינים את הגרסה החדשה מעל הקיימת. השירים והפלייליסטים נשמרים.
